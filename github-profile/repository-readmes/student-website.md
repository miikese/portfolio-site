# Student Website

A foundational web-development project built with HTML, CSS, and JavaScript. The project explores a student-focused website with home, about, contact, and support navigation.

## Purpose

Practice page structure, styling, and basic browser interactions before moving on to more substantial applications. This repository is an early learning project.

## Explore the source

Clone the repository and inspect the included HTML, CSS, and JavaScript files:

```sh
git clone https://github.com/miikese/student-website.git
cd student-website
```
